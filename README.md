# Letema Stationery & Internet Café - Mbeya, Tanzania

## Mfumo wa Teknolojia (Tech Stack Explanation)

* **Node.js na NPM:** Tumesakinisha Node.js kama mazingira ya uendeshaji (Runtime Environment) ili kuwezesha utendaji kazi wa zana za kisasa za wavuti kama Vite na React nje ya kivinjari (Browser). NPM (Node Package Manager) inatusaidia kusakinisha, kusasisha, na kusimamia maktaba (Libraries/Dependencies) zote za programu yetu kwa urahisi.
* **Vite Framework:** Tumechagua kutumia Vite badala ya zana ya kizamani ya `create-react-app` kutokana na kasi yake ya juu sana (Lightning-Fast Bundling) na ufanisi mzuri katika utumiaji wa rasilimali za kifaa. Vite haili chaji nyingi wala haihitaji kiasi kikubwa cha RAM ya simu, jambo ambalo ni nguzo kuu tunapofanya kazi ndani ya mazingira ya Termux.
